# Project Overview

PostgreSQL in 30 Days is a structured portfolio project documenting my journey of learning PostgreSQL from fundamental concepts to relational database design.

The final project demonstrates the practical implementation of a mini e-commerce database system.

- Relational database design.
- Aggregate functions.
- JOIN operations.
- Analytical SQL queries.
- Database constraints.
- Real-world data modeling.
